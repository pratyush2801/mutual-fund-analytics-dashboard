# mutual-fund-analytics-dashboard
Tableau | SQL | Data Analytics | Interactive dashboard for mutual fund performance, NAV analysis, KPIs, and historical trends.

Overview:
This project presents an interactive Tableau dashboard for analyzing mutual fund performance using historical NAV data. It provides insights into fund growth, latest NAV, historical records, and fund launch trends through dynamic KPIs and visualizations.

Dashboard Preview:
<img width="1366" height="768" alt="Dashboard 1" src="https://github.com/user-attachments/assets/ac498aee-01f7-4b86-96f0-dfc1121995b3" />

Features:
Total Mutual Funds KPI
Average NAV
Highest NAV
Lowest NAV
Average Growth (%)
Top 10 Funds by Latest NAV
Top 10 Funds with Most Historical Records
Funds Launched by Year
Top 10 Oldest Funds
Interactive Filters

Tools Used:
Tableau
SQL (MySQL)
Excel
CSV Dataset

| KPI            | Description        |
| -------------- | ------------------ |
| Total Funds    | Number of schemes  |
| Average NAV    | Average latest NAV |
| Highest NAV    | Maximum NAV        |
| Lowest NAV     | Minimum NAV        |
| Average Growth | Growth percentage  |

Insights:
Example:
More than 15,000 mutual fund schemes are available.
The highest recorded NAV exceeds ₹2.5 million.
Fund launches accelerated significantly after 2013.
A small number of funds have extremely high NAV values, while the majority remain in a lower NAV range.
Several funds maintain long historical records, indicating consistent reporting over many years.
